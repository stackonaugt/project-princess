# Meredith music

Seb's festival music. To change it, drop MP3s here and list their file names
in `MF_MUSIC` in `src/data/meredith.js`:

- `day`: tracks played one after another round the festival by day
- `night`: the same, after dark
- `mamaking`: the Mama King set (the dance)
- `icekids`: the Ice Kids set; the curse waits `curseAfter` seconds (40)

The Amphitheatre and the Pink Flamingo play them loudest. An empty list or
name plays the built-in synth beat and crowd instead.
