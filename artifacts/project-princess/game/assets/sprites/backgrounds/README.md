# Battle background artwork

Drop your own PNG files into this folder. You do not need to use the Studio or edit game data.

Use a battle zone ID or suburb ID as the filename, for example `fleming.png` or `laverton.png`. `default.png` is the fallback for locations without a specific background. Zone art takes priority over suburb art, which takes priority over the default. Optional `*-night.png` versions appear after dark.

A 320 x 180 pixel landscape PNG is a good starting size. Draw the scenery only; the game adds the pets, people, effects and controls. Leave open ground in the lower-left and middle-right for the fighters. The full guide and filename rules are in `../README.md` under “Draw your own battle backgrounds”.
